三步快速开始

简单几步，即刻开启AI商业洞察之旅

1

克隆仓库并安装依赖

git clone https://github.com/Samge0/BizOwl.git
cd BizOwl && npm install
2

启动开发模式

npm run dev
3

构建生产版本

npm run build:win (Windows)
npm run build:mac (macOS)
npm run build:linux (Linux)

支持 macOS 12+ / Windows 10+ / Linux 全平台

常见问题

关于BizOwl的疑问解答

BizOwl是免费的吗？

是的，BizOwl完全开源免费，采用MIT协议发布。您可以自由使用、修改和分发。但需要注意，企业数据查询功能需要您自行配置有效的第三方服务凭证（如企查查），这些第三方服务可能需要付费。

我的数据安全吗？

BizOwl非常重视用户隐私。所有凭证仅存储在本地设备上，不会上传到任何第三方服务器。应用本身不收集或传输用户数据，企业查询功能直接与您配置的数据源通信。

支持哪些AI模型？

BizOwl兼容所有OpenAI API格式的模型，包括vLLM、Ollama、本地部署的模型以及各类云端API服务。只要遵循OpenAI API标准，即可无缝接入。

需要什么系统要求？

BizOwl支持macOS 12+、Windows 10+以及主流Linux发行版。建议至少4GB内存，对于AI对话功能，您需要配置相应的API服务或本地模型。

如何贡献代码或报告问题？

欢迎通过GitHub提交Issue和Pull Request。请在提交前查看项目的贡献指南。对于功能建议和Bug报告，请提供详细的复现步骤和环境信息。

开源 · 自由 · 安全

BizOwl是一个独立的个人开源项目，采用MIT协议发布。项目本身不包含任何企业数据，数据查询功能依赖用户自行配置有效凭证，所有凭证仅存储在本地，不会上传到任何第三方服务器。
