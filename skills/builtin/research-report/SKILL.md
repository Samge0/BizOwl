# BizOwl 深度研究报告工作流

本技能是研究报告的**操作手册**：从需求确认到 PDF 交付的 7 阶段标准流程、评分方法论、数据采集规范、图表规范、report_export 工具调用方式。

## 何时触发

- 用户说"帮我做一份关于 XX 主题/行业的研究报告"
- 用户说"对比分析 A 和 B 两个方案并打分"
- 用户说"评估 XX 主题的市场前景并导出 PDF"
- 用户点击助手消息下方的「深度研究报告」入口（会附带本次会话内容 + 方向指导）
- 任何"研究报告 / 行业分析 / 方案评估 / 市场前景 + PDF"组合的需求

## 篇幅与深度原则

**默认目标 15-30 页，内容丰富时不设上限。** 只受限于真实可获取的数据量：
- 数据充足 → 深入展开：每章 3-6 小节、配图表、多源交叉验证、案例剖析
- 数据不足 → 如实标注缺口 + 降置信度，**绝不用幻觉内容填充篇幅**
- 宁可多写一章把一个维度挖透，也不要为了"简洁"砍掉有价值的分析

推荐章节结构（行业研究为例，按主题裁剪）：
1. 行业概述与定义（边界、产业链上下游、核心术语）
2. 市场规模与增长（总量、增速、分段预测、CAGR、口径来源差异）
3. 竞争格局（头部玩家份额、集中度 CR4/CR8、进入壁垒、差异化定位）
4. 技术与产品成熟度（主流技术路线对比、迭代节奏、瓶颈）
5. 政策与监管环境（现行法规、补贴、准入门槛、国际对比）
6. 产业链与价值链（上中下游、关键环节利润分布）
7. 驱动因素与风险（增长驱动、替代风险、地缘风险、周期性）
8. 典型企业案例分析（2-4 家代表性企业画像）
9. 未来 3-5 年趋势研判（情景分析：乐观/基准/悲观）
10. 投资与战略建议（针对目标读者）

## 7 阶段工作流

### 阶段 1 · 框架设计
- 用当前系统时间作为报告时间基准（禁止用训练知识里的过期日期）
- 明确：主题边界、报告类型、目标读者、重点关注维度
- 产出报告大纲 + 评分维度草案

### 阶段 2 · 多源数据采集
- 优先 `web_search`（多次、多查询变体：中文+英文、近 N 年限定）
- 关键数字至少 2 个独立来源交叉验证
- 每条数据记录：指标名 / 数值 / 单位 / 时间 / 来源标题 / 来源URL / 可信度(1-5)
  - 5=政府/交易所原始数据；4=研究机构/上市公司公告；3=权威媒体；2=一般媒体/博客；1=未署名/UGC
- 绝不编造数据；采不到标"数据缺口"

### 阶段 3 · 数据清洗结构化
去重、统一单位（货币口径注明本位币/汇率/年份）、冲突仲裁（可信度优先、时间最新优先）、缺失标注。

### 阶段 4 · 多维度打分
- 每维度 0-10 分（可 1 位小数）
- 权重合计 100%（默认等权；重点关注维度上调 1.5-2x；单一维度不超 40%）
- 每维度必须写 **2-4 句评分依据**（有数字、有对比、有判断逻辑）
- 置信度：高（≥3 独立可靠来源近 1 年）/ 中（2 来源或数据 1-2 年前）/ 低（仅 1 来源或数据>2 年）
- 综合置信度 <0.5 时摘要显式提示"数据基础较弱，结论需谨慎"

### 阶段 5 · 图表可视化（高密度要求）

**一份合格报告应包含至少 4-6 张图表**，散布在各章节，真实反映章节内数据。所有图表 class 已在 PDF 模板内建样式。

| 类型 | HTML 结构 | 适用场景 |
|------|-----------|---------|
| 柱状图（横向） | `.bar-row > .bar-label + .bar-track > .bar-fill[style=width:N%] + .bar-val` | 数值对比/排名（市场份额、注册资本、专利数） |
| 评分卡 | `.score-cards > .dim-card > .dim-name + .dim-score + .dim-bar > .dim-bar-fill[style=width:N0%]` | 多维度评分速览 |
| 时间线 | `.timeline > .tl-item > .tl-date + .tl-title + .tl-desc` | 发展历程/里程碑/融资节点/政策演进 |
| KPI 指标卡 | `.kpi-grid > .kpi-card > .kpi-label + .kpi-value + .kpi-unit + .kpi-delta(.kpi-up/.kpi-down)` | 核心指标突出（市场规模、CAGR、渗透率） |
| 进度环 | `.ring-row > .ring-card > svg[圆形进度] + .ring-label` | 达成度/渗透率/自给率 |
| 数据表格 | `<table>`（.section-body table 已有样式） | 精确多字段对比（规格、财务、政策清单） |
| 评分总表 | score_table 参数 | 必出：维度/权重/得分/置信度/依据 |

**柱状图规则**：bar-label 文字 ≤12 字（超长缩写+正文说明全称）；数值归一化到 0-100% 作为 bar-fill width；bar-val 写真实数值+单位。

**进度环 SVG**：圆周=2πr，用 `stroke-dasharray="周长"` + `stroke-dashoffset="周长×(1-N%)"` 画进度。

**图表防糊规则（强制）**：
- 文字间距充足（bar-row margin≥7px，timeline tl-item margin≥12px）
- 长文本截断或换行（bar-label 用 ellipsis，timeline 标题单行）
- 每张图用 `.chart-box` 包裹（自带 page-break-inside:avoid）
- 数值/单位明确标注
- 一张图只表达一个核心信息，超 8 项拆成多张

### 阶段 6 · PDF 生成
调用 `report_export` 工具，参数结构：
```
{
  title, subtitle, report_type,
  abstract,            // 摘要（\n 分段）
  total_score, confidence,
  chapters: [{ title, sections: [{ heading, body }] }],  // body 支持 HTML，章节内图表直接嵌这里
  score_table: { headers: [...], rows: [[...]] },
  charts_html,         // 跨章节综合图表（可空，章节内图表优先）
  references: [{ id, title, url, accessed }],
  appendix             // 附录 HTML（数据缺口说明/术语表/方法论）
}
```

工具会自动：①校验标题非空、chapters 非空（空则返回 error 不生成空 PDF）；②清理内联强制分页样式（避免大片空白）；③清理 undefined 章节标题。

### 阶段 7 · 交付说明
给用户：PDF 绝对路径、一句话核心结论、总评分（加权总分+置信度）、数据强项、数据短板、下一步建议。

## 报告结构（模板内置，自然流式排版）

1. 封面（标题/副标题/报告类型/生成日期/作者）— 独占页
2. 摘要（核心结论 + 总评分卡）— 独占页
3. 目录
4. 正文各章（**自然流式，不强制换页**，章节间细分隔线）
5. 评分总表（紧跟正文）
6. 图表（紧跟）
7. 参考文献（紧跟）
8. 附录

## 工作准则（不可妥协）

- **溯源**：每个数字/判断都要能在参考文献找到出处；写不出出处的结论打"待考证"
- **可分离**：先摆事实层，再给评分层，绝不把判断伪装成事实
- **诚实面对数据缺口**：信息不足降置信度并明示，不用幻觉填充
- **丰满而非注水**：多用图表/案例/多源对比让报告充实；但每论点都要有数据支撑，不为凑页数写空话
- **交付即闭环**：PDF 未真实生成不算完成

## 常见坑

- 模型知识截止日期早于真实日期 → 搜索查询带过期年份。先取当前时间
- 单一来源当结论 → 关键数字必须交叉验证
- 数据编造 → 禁止。采不到就标"数据缺口"并降置信度
- 图表文字堆叠 → 标签限制字数 + 充足间距 + 一图一信息
- 大片空白 → 不要在 body 里写 page-break 样式，模板已统一控制分页
