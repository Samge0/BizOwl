# 多源企业尽调

## 使用场景

- "帮我做一份 XX 公司的尽调报告"
- "分析一下 XX 公司的投资价值"
- "XX 公司的竞争对手有哪些？"
- "XX 公司的融资历程是怎样的？"

## 尽调框架

### 1. 企业画像
- 公司全称、统一社会信用代码、法定代表人
- 注册资本（实缴 vs 认缴）、成立日期、经营期限
- 注册地址、企业类型、行业分类

### 2. 股权结构
- 股东列表及持股比例
- 股权穿透（向上追溯到实际控制人）
- 对外投资（向下扩展到控股/参股企业）

### 3. 风险扫描
- 行政处罚记录
- 失信被执行人信息
- 经营异常名录
- 严重违法记录
- 司法案件（裁判文书网公开信息）

### 4. 竞争分析
- 同行业主要竞争对手
- 市场份额估算（基于公开信息）
- 核心产品/服务对比

### 5. 融资与发展
- 历史融资轮次（天使/A/B/C/IPO）
- 投资机构列表
- 重要里程碑事件

## 工作流程

1. 调用 `enterprise_lookup` 或 `web_search` 获取各维度原始数据
2. 对数据进行交叉验证（多个来源互相比对）
3. 标注数据时效性和可信度
4. 生成结构化 Markdown 报告
5. 如用户需要，通过 `document_export` 导出为 DOCX/PDF

## 数据声明

所有数据来自公开网页，未经专业数据平台核验。重要决策前建议通过官方渠道二次确认。
