# 企业信用核查

## 使用场景

- "查一下 XX 公司的信用状况"
- "XX 公司有没有失信记录？"
- "我们要和 XX 公司合作，帮我做个风险评估"
- "XX 公司是老赖吗？"

## 五维核查框架

### 维度一：工商合规性
- 数据源：国家企业信用信息公示系统（gsxt.gov.cn）
- 检查项：经营状态、经营异常名录、严重违法失信名单
- 查询方式：`web_search` site:gsxt.gov.cn 企业名称

### 维度二：司法风险
- 数据源：中国裁判文书网（wenshu.court.gov.cn）、中国执行信息公开网（zxgk.court.gov.cn）
- 检查项：涉诉案件数量、被执行人记录、失信被执行人（老赖）
- 查询方式：`web_search` site:zxgk.court.gov.cn + site:wenshu.court.gov.cn

### 维度三：行政处罚
- 数据源：信用中国（creditchina.gov.cn）
- 检查项：行政处罚公示、行政许可变更
- 查询方式：`web_search` site:creditchina.gov.cn 企业名称

### 维度四：税务合规
- 数据源：国家税务总局重大税收违法案件公告
- 检查项：欠税公告、重大税收违法
- 查询方式：`web_search` 企业名称 税收违法 site:chinatax.gov.cn

### 维度五：舆情风险
- 数据源：综合网页搜索
- 检查项：负面新闻、消费者投诉、监管约谈
- 查询方式：`web_search` 企业名称 负面 OR 投诉 OR 处罚 OR 违规

## 输出格式

```
## 企业信用核查报告：[企业名称]

### 信用评级：⭐⭐⭐⭐☆（4/5）

| 维度 | 状态 | 详情 |
|------|------|------|
| 工商合规 | ✅ 正常 | 未发现经营异常 |
| 司法风险 | ⚠️ 关注 | 涉诉案件 3 起 |
| 行政处罚 | ✅ 无 | 未发现行政处罚 |
| 税务合规 | ✅ 正常 | 未发现欠税 |
| 舆情风险 | ⚠️ 关注 | 近期有消费者投诉 |

### 建议：[基于核查结果的建议]
```

## 重要声明

本核查仅基于公开信息，不构成专业法律或投资建议。重要商业决策前请通过官方渠道或专业机构进行深度尽调。
