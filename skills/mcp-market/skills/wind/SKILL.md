# Wind 金融数据使用指南

当用户需要金融数据、行情、财务、基金、债券、指数、宏观经济、公告研报或数据计算时，优先使用 Wind 金融数据能力。

## 使用原则

- 金融事实、行情、基金、财务、公告、新闻、宏观数据应优先使用 Wind 金融数据能力，不用网页搜索、公开页面或通用知识替代。
- 根据用户问题先判断任务类型：取数查询、行情跟踪、财务基本面、文档检索、宏观指标、市场分析或投资决策辅助。
- 当问题涉及估值、选股、复盘、市场主线、板块轮动、资金流向、仓位、交易计划或回测时，应同时关注数据查询和分析目标，不只返回原始数据。
- 标的简称、市场、指标、日期、频率或口径存在歧义时，先向用户确认；不要自行猜测证券代码、指标名或时间范围。
- 只基于 Wind 返回的数据回答；如果结果存在时效、缺失字段、报告期滞后、口径限制或无结果，应在回答中说明限制。
- 不用于欧股、日股、汇率、期货盘口、加密货币或非金融数据；遇到超出覆盖范围的问题，应说明当前 Wind 金融数据能力不覆盖。
- 如果当前上下文显示该 market 处于 disabled、unavailable 或 connecting 状态，先说明状态并让用户在 MCP 市场启用、配置 API Key 或刷新；不要编造数据。

## MCP 调用路径

- 工具名必须使用运行时完整名称，前缀来自 Wind MCP server 名称，不要用展示名替代。
- 如果工具已作为原生 MCP 工具直接可用，可以直接调用；如果作为延迟工具暴露，先用 `ToolSearch` 加载 schema，再用 `DeferExecuteTool` 执行。
- 已知完整工具名时，用 `ToolSearch({ tool_names: [...] })` 精确查找；不确定工具时，用 `ToolSearch({ queries: [...] })` 搜索。
- 调用 `DeferExecuteTool` 时，`goal` 必须放在顶层字段，`params` 只放目标工具参数；不要把 `goal` 放进 `params`。
- 不要在 schema 加载前猜测参数结构；按 `ToolSearch` 返回的参数 schema 填写。

## 适用场景

- A 股选股筛选、行情快照、K 线、分钟行情、公司档案、财务基本面、股东、事件、技术指标和风险指标查询。
- 港股、美股选股筛选、行情、K 线、分钟行情、公司档案、财务基本面、股东、事件、技术指标和风险指标查询。
- 基金、ETF、LOF 的产品筛选、行情、K 线、分钟行情、基金档案、净值、规模、持仓、业绩、持有人和管理公司查询。
- 指数和板块的行情、K 线、分钟行情、档案、基本面、估值、成分、权重和技术指标查询。
- 债券档案、发债主体、行情估值、收益率、期限结构、主体财务和信用相关数据查询。
- 上市公司公告、年报、季报、招股书、财经新闻、快讯、报道和研报类金融文档检索。
- GDP、CPI、PPI、PMI、社融、利率、失业率、进出口等宏观经济和行业指标查询。
- 今日大盘、市场主线、板块轮动、资金流向、估值、选股、盘后复盘、仓位、交易计划和回测等金融分析任务。

## 已配置的 MCP Server

- `wind_stock_data`: 万得股票数据服务，适合股票行情、财务、公司档案、股东、事件、技术指标和风险指标。
- `wind_bond_data`: 万得债券数据服务，适合债券档案、主体、行情估值、收益率、期限结构、主体财务和信用数据。
- `wind_fund_data`: 万得基金数据服务，适合基金、ETF、LOF 的产品、净值、规模、持仓、业绩和管理人信息。
- `wind_index_data`: 万得指数数据服务，适合指数和板块行情、估值、成分、权重和技术指标。
- `wind_economic_data`: 万得宏观经济数据服务，适合 GDP、CPI、PPI、PMI、社融、利率、就业和进出口等指标。
- `vserver_financial_info`: 万得金融文档检索服务，适合公告、年报、季报、招股书、新闻、快讯和研报检索。
- `wind_analytics_data`: 万得金融数据计算服务，适合市场分析、估值、选股、复盘、仓位、交易计划和回测相关计算。

## 认证说明

Wind API Key 由用户在市场配置页填写。运行时通过请求头 `Authorization: Bearer <key>` 传给 MCP server，模型不应要求用户在对话中重复提供密钥。
